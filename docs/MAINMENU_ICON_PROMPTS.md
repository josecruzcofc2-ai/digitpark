## PROBLEMA COMÚN Y CÓMO EVITARLO

Las IAs generan fondos blancos/de color porque están entrenadas en "app icons" (icono + fondo cuadrado iOS/Android).
Para evitarlo, NUNCA uses frases como "app icon" o "icon design". Usa en cambio:
**"UI glyph symbol"**, **"vector symbol"**, **"UI sticker"**, **"graphic asset"**

## PREFIJO UNIVERSAL (copiar al inicio de CADA prompt)

```
Create a single flat UI symbol for a mobile app interface. This is a graphic design asset, NOT a product photo, NOT a logo on a background, NOT an app icon tile. Style: flat bold minimalist, identical to Google Material Design icons or Apple SF Symbols — pure geometric shapes with zero decoration. Render ONLY the symbol shape itself. ⚠️ CRITICAL: The output image must have a 100% fully transparent background — alpha channel = 0 on every pixel that is not part of the symbol. No white fill, no dark fill, no colored rectangle, no circle behind the icon, no vignette, no gradient background, no drop shadow, no outer glow, no background of any kind. The symbol floats alone on empty transparent space, just like a PNG icon asset exported from Figma or Adobe Illustrator. Output: 1024x1024 pixels, PNG-32 format, RGBA color space, transparent background.
```

## NOTAS TÉCNICAS DE USO

### Para ChatGPT / DALL-E 3
- Usa exactamente el texto del bloque del prompt de cada icono
- Si aparece fondo blanco: pide "remove all background pixels, make transparent"
- O pide con `--transparent` si tu herramienta lo soporta
- Alternativamente: genera la imagen y usa remove.bg o Photoshop para eliminar fondo

### Para Midjourney
- Añade al final: `--no background shadow texture gradient white black gray floor`
- Añade: `--style raw --v 6`
- Para íconos outline: añade `--no fill solid color inside shape`

### Para Stable Diffusion / ComfyUI
- Negative prompt: `background, white background, colored background, texture, gradient, shadow, glow, 3d render, realistic, photo, dark background, vignette, frame, border`
- Checkpoint: use a vector/illustration model

### Resolución final en proyecto
Los iconos se usan en Unity en tamaños pequeños (24-64px). No importa que sean 1024px — Unity los downscala limpiamente.

### Proceso de integración
1. Generar imagen con el prompt
2. Verificar fondo transparente (abrir en cualquier editor con checker background)
3. Si tiene fondo blanco: usar remove.bg, Photoshop "Select Subject", o Figma background remover
4. Exportar como PNG-32 con canal alpha
5. Reemplazar el archivo en `Assets/_Project/Art/Icons/[carpeta]/`
6. Unity detecta automáticamente el cambio al importar
